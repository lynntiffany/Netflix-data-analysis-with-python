# Netflix Data Analysis with Python

## Overview

An exploratory data analysis project investigating Netflix's content catalogue using Python, pandas, and Matplotlib. The project covers data cleaning, content distribution, country analysis, release trends, ratings, and genre exploration.

## Objectives

* Inspect, clean, and standardize the dataset.
* Explore movies, TV shows, countries, and release trends.
* Analyze content ratings and genre distributions.
* Create visualizations and communicate meaningful insights.

## Tools & Technologies

* Python
* pandas
* Matplotlib
* Jupyter Notebook

## Key Findings

* TV-MA was the most common content rating, accounting for 36.5% of titles.
* TV-14 accounted for 24.5% of titles.
* Together, TV-MA and TV-14 represented 61% of the dataset.
* TV shows had a higher proportion of TV-MA titles (42.9%) than movies (33.7%).

## Skills Demonstrated

Data cleaning, exploratory data analysis (EDA), data aggregation, percentage calculations, data visualization, and insight generation.


## Conclusion

This project demonstrates a structured approach to data analysis, from data preparation to visualization and evidence-based interpretation.
